## The excuse

> HR lost my leave form and approved 3 days off for last Tuesday.

One line, 63 characters. HR lost the form, approved three days off, and the days are already gone — a bureaucratic blunder with a named culprit, a concrete number, and the punchline landing on the last two words.

## How it works

`main.py` writes the excuse to `/output/entry.txt`. Nothing else is needed.

## Building the entry

The excuse won a 12-candidate blind tournament judged against the bounty brief (batch 2, after batch 1's winner failed calibration). It then faced the previous genre winner in a blind calibration matchup twice and lost both times (0-2, then 0-2); the protocol allows only one tournament re-run, already used, so the tournament winner was built as instructed.

## Run it

```sh
python3 main.py
```
